# Adding your content

Liccium reads each file once to generate its ISCC codes and stores the results in a local database on your computer. The file itself is not modified, moved or uploaded.

## Three ways to add content

| Option     | What it does                                                                                                    |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| Add file   | Adds a single file.                                                                                             |
| Add folder | Adds every supported file in a folder and its subfolders.                                                       |
| Add URL    | Adds a web article by its address – the article text and the images embedded in it each receive their own ISCC. |

## Pinned folders

Folders you add stay in the sidebar as pinned folders. Liccium watches them and updates your library when files are added, renamed, moved, changed or deleted. A file that is renamed or moved keeps its information and declarations, because Liccium recognises it by its content.

Files that are stored only in the cloud – for example in iCloud Drive or Google Drive and not yet downloaded – are not scanned until they are available on your computer.

## Supported formats

| Media  | File types                                           |
| ------ | ---------------------------------------------------- |
| Images | JPG, PNG, GIF, SVG, WebP, HEIC/HEIF                  |
| Text   | PDF, EPUB, MOBI, AZW, DOC, DOCX, TXT, RTF            |
| Audio  | MP3, M4A, AAC, FLAC, WAV, OGG, Opus, WMA, AIFF, ALAC |
| Video  | MP4, MOV, MKV, AVI, WebM, FLV, WMV, M4V, 3GP, OGV    |

To learn more about ISCC codes, visit [https://iscc.io](https://iscc.io).

## Existing metadata

When you add images, Liccium reads the IPTC fields already stored in them – creator, credit line, copyright notice, keywords and licence information. Photographers who maintain this information in Lightroom or other tools do not have to enter it twice.

## Removing content

You can remove any file or folder from Liccium. This removes it from your mirrored library only – the file stays where it is on your computer, and declarations you already published remain on record.
