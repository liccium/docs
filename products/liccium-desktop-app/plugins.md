# Plugins

Plugins decide which kinds of information you can attach to a declaration. Each plugin adds a set of fields to the edit page of a file. You activate the plugins you need in Settings.

## Defaults and individual files

For most plugins you can set defaults that apply to all files – for example your name as creator, or your preference on AI training. On each file you can change any field, or switch a plugin off for that file only without deactivating it globally.

Fields that come from your defaults are marked Default on the edit page, so you can see which values are general and which belong to the individual file. Before you declare, Liccium shows every field that will be signed. The declaration contains exactly what you see.

## Rights status

Some information can only be stated by the person or organisation that holds the rights. On each file you indicate whether you are the rightsholder.

| Requires rightsholder status           | Can be stated by anyone |
| -------------------------------------- | ----------------------- |
| Creative Commons, TDMrep, C2PA signing | FAIA, IPTC, Text, Music |

## Rights plugins

### Creative Commons

Attaches a Creative Commons licence to the declaration, so others can see what they may and may not do with the work. You can choose CC0 1.0 or one of the six CC 4.0 International licences – BY, BY-SA, BY-ND, BY-NC, BY-NC-SA and BY-NC-ND. The declaration links to the official licence text.

### TDMrep

Reserves or allows the use of your work for text and data mining, including AI training, following the W3C TDM Reservation Protocol (TDMRep), a Community Group specification. TDMrep is not a ratified standard.

| Field      | Values                                                                                              |
| ---------- | --------------------------------------------------------------------------------------------------- |
| Preference | Reserved or allowed                                                                                 |
| Policy URL | Optional link to your licensing terms, for example a page where AI developers can request a licence |

Declarations with a TDMrep preference are listed on Optout.directory. For background, see TDM·AI – Registry-Based Opt-Out Declarations.

## Transparency plugins

### FAIA – Fair AI Attribution

Discloses whether and how AI was involved in creating a work.

| Flag                              | Meaning                                       | Activity codes                                     |
| --------------------------------- | --------------------------------------------- | -------------------------------------------------- |
| HCC – Human Creative Contribution | Created by a person without generative AI     | None                                               |
| AAC – AI-Assisted Creation        | Created by a person with the help of AI tools | Co-Creation, Contribution, Enhancement, Refinement |
| AIG – AI-Generated                | Generated by an AI system                     | Transformation, Analysis, Undefined                |

You can also name the AI system and version used. Declarations with FAIA information are published on FAIA.io. For background, see [FAIA – Fair AI Attribution](https://faia.liccium.com/).

### C2PA – Content Credentials

Creates a signed C2PA manifest for a declared file, which C2PA-aware tools can read. The manifest is stored as a separate file next to the declaration and connected to the content by its ISCC, so your original file is not modified. Liccium also shows the content of the manifest on the file's detail page.

### IPTC

### Text

Bibliographic information for articles, posts and books: authors, contributors, translators, title, subtitle, description, keywords, publisher, journal, volume, pages, ISSN, ISBN, DOI, release date and language.

### Music

Release information for audio: artist, title, description, album, copyright notice, copyright holder, and the identifiers ISRC (recording), ISWC (musical work) and ISNI (party).

### Plans

The Creative Commons, TDMrep and FAIA plugins are free. The IPTC, Text, Music and C2PA plugins are included in the Creator plan.
