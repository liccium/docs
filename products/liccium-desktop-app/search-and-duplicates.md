# Search and duplicates

Because Liccium knows the content fingerprint of every file in your library, it can find files by what they contain, not only by their names.

## Search

Press Cmd + F anywhere in the app to open the search. You can search by title, creator, description, full text, ISCC or declaration ID.

Advanced search adds filters for:

* media type;
* rights status;
* TDMrep preference;
* FAIA flag;
* C2PA signature;
* declared or not yet declared;
* date range;
* folder;
* your own labels.

## Labels

Labels let you group files across folders – for example by client, project or publication. You can filter search results by label and see all files with a label on one page.

## Finding copies and similar content

Liccium compares ISCC codes to find files that share their content, even when file names, formats, sizes or resolutions differ. Right-click a file and choose to find matches, or open the duplicates view for your whole library.

Results are grouped by how closely they match:

| Level               | Meaning                                                                         |
| ------------------- | ------------------------------------------------------------------------------- |
| Exact copy          | The files are identical                                                         |
| Same content        | The same content in a different file – for example another format or resolution |
| High similarity     | At least 86 % similar – for example a crop or light edit                        |
| Moderate similarity | At least 78 % similar                                                           |
| Broad match         | At least 69 % similar – may include unrelated content, so check the results     |

## Searching with text

You can paste a passage of text and find documents in your library that contain the same or similar text.

## Semantic matching

Optional semantic matching finds content with a similar meaning, not only similar form – for example two texts expressing the same ideas in different words. It is switched off by default and can be activated in Settings → System. The model runs on your computer; no content is uploaded.

## Comparing two files

You can compare two files side by side to see how similar they are, and which ISCC units match.
